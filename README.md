# Empty Taco

Weekend Tampa hot dog cart. **A hot dog can fix a bad day.**

Regular, vegan, and keto-friendly. **$3** dog · **$5** with chips and a drink · **$20** to send one to a friend.

**Live site:** https://karmicfuture.github.io/EmptyTaco/

This repo is the website. `index.html` is at the root so GitHub Pages can serve `main` `/`.

```bash
python3 -m http.server 8080
```
